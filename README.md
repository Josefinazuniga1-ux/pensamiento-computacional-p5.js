## Análisis de la Obra
Para esta entrega, se seleccionó una obra asimétrica compuesta por rectángulos ortogonales. El proceso de traducción implicó:
* **Abstracción:** Identificar los pesos visuales y las proporciones de cada bloque.
* **Coordenadas:** Mapear cada figura en un lienzo de 710x450 píxeles.
* **Color:** Extracción de la paleta exacta (Rojos terracota, Azules profundos, Verdes mate y Amarillo mostaza).
* **Cómo tradujeron la imagen:** Con ayuda de Photoshop, ocupando las guias Hice un sistema de grilla para ir guandome de la ubicacion y con el cuenta gotas el color aproximado.
* **Dificultades y soluccion:** lo mas dificil fue saber el lugar exacto de cada rectangulo, pero gracias a la ayuda de una grilla que cree, separando la obra en cuadrados, logre ubicarme mas o menos en el lienzo.
